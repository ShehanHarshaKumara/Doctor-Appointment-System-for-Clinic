A modern and smart clinic management web application designed to manage doctor appointments, patient records, staff operations, and clinic administration efficiently.

## 🚀 Features

- 👨‍⚕️ Doctor appointment booking
- 🧑‍🤝‍🧑 Patient management
- 🏥 Clinic staff operations
- 📋 Medical record tracking
- 📅 Appointment scheduling
- 🔐 Secure multi-panel system concept
- 📱 Modern responsive patient website UI
- ⚡ Fast frontend built with Vite

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- CSS
- Material UI
- Radix UI
- Lucide React
- Motion / Animation Libraries

⚙️ Installation & Run
1. Clone the repository
git clone https://github.com/ShehanHarshaKumara/Doctor-Appointment-System-for-Clinic.git
2. Open project folder
cd Doctor-Appointment-System-for-Clinic
3. Install dependencies
npm install
4. Start development server
npm run dev
5. Build project
npm run build
👥 System Panels
Patient Panel

Patients can view clinic services, book doctor appointments, manage profile details, and track health-related information.

Staff Panel

Staff members can manage patient details, appointment numbers, medicine records, and daily clinic operations.

Admin / Doctor Panel

Doctors and admins can monitor appointments, manage patient records, check clinic activities, and control system data.

🎯 Project Purpose

This project was developed to reduce manual clinic work, improve appointment handling, and provide a user-friendly digital platform for patients, staff, and doctors.
